# VentaNexIA Autonomous Operator

## Operating model
VentaNexIA is managed as an automation-first commercial operating system.

### Daily automatic operation
- review CRM pipeline, lead quality, pending next actions and stale opportunities;
- inspect website/deployment health when connectors are available;
- review booking, payment and onboarding state;
- prepare SEO/content opportunities;
- surface only exceptions that need owner approval;
- execute reversible low-risk actions inside established policy.

### Actions requiring owner approval
- prices, discounts or contractual commitments;
- first launch of a new outbound campaign/channel or meaningful volume increase;
- credential changes and production installation on a customer system;
- irreversible data deletion;
- legal-sensitive responses, complaints and high-risk commercial exceptions.

### Client provisioning target
New client -> tenant -> knowledge intake -> CRM/email/calendar connection -> widget/agent installation -> Guardian approval -> production activation -> monitoring.

### Owner interaction
The owner should receive a concise operator brief, not a list of manual tasks.
