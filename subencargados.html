Política de subencargados y proveedores de IA

VentaNexIA · ECOJAFER S.L. · Versión 2026-09-17-SUB-v1

VentaNexIA puede utilizar proveedores tecnológicos para prestar determinados módulos. No todos los proveedores intervienen en todos los clientes ni todos reciben los mismos datos. Solo se utilizarán cuando sean necesarios para la función contratada y con el alcance técnico correspondiente.

Autorización general. Al aceptar el Anexo RGPD, el cliente autoriza con carácter general el uso de subencargados necesarios para prestar el servicio, sujeto al régimen de información y oposición previsto en dicho anexo.

Proveedores conectados por el cliente

Cuando el cliente solicite conectar herramientas propias —por ejemplo CRM, correo, WhatsApp/Meta, telefonía, calendario, almacenamiento, ERP u otras APIs— esos proveedores podrán actuar como responsables independientes, encargados o subencargados según la relación jurídica concreta. El cliente será informado del alcance antes de activar una conexión que implique tratamiento adicional de datos personales.

Proveedores no incluidos automáticamente

La inclusión de una categoría o ejemplo en esta política no implica que ese proveedor esté activado para todos los clientes. VentaNexIA procurará aplicar minimización de datos y utilizar únicamente los servicios necesarios para cada módulo.

Cambios en la lista

VentaNexIA podrá incorporar o sustituir proveedores cuando sea necesario para seguridad, continuidad, rendimiento o evolución del servicio. Cuando el cambio pueda implicar tratamiento de datos personales del cliente y sea material, se actualizará esta página y se comunicará con antelación razonable. El cliente dispondrá de treinta (30) días desde la notificación para formular una objeción razonada por motivos de protección de datos.

Transferencias internacionales

Cuando un proveedor trate datos fuera del Espacio Económico Europeo, VentaNexIA utilizará proveedores que contemplen mecanismos de transferencia válidos conforme a la normativa aplicable, como decisiones de adecuación, cláusulas contractuales tipo u otras garantías reconocidas legalmente.

Consulta y contacto

Para cuestiones sobre subencargados o protección de datos, el cliente puede escribir a privacidad@ventanexia.es.
