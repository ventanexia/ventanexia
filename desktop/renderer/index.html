ASISTENTE DE DETECCIÓN

No sé dónde guarda mi programa los datos

Si usas FacturaPlus, ContaPlus, Sage, A3, FactuSOL, un CRM, un ERP u otro programa, VentaNexIA puede buscar qué carpetas parecen contener datos de empresa.

Privacidad: durante esta búsqueda solo se analizan localmente nombres de carpetas y archivos, tipos, fechas y tamaños. No se abre el contenido de los documentos y no se envían esos datos a Internet. Tú decides después qué carpeta autorizar.

ASISTENCIA SEGURA

Ayuda remota solo cuando tú la autorizas

VentaNexIA no mantiene acceso remoto permanente. Para esta primera versión abrimos Asistencia rápida de Windows desde aquí. Tú ves la sesión y puedes cerrarla en cualquier momento.

Permiso temporalEl soporte debe pedirte un código y tú debes aceptar la conexión en la herramienta de Windows.
