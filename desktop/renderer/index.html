ALTA DE NUEVO CLIENTE

Así verá un cliente su puesta en marcha

Esta pantalla reproduce el recorrido que queremos para un cliente nuevo: contratar, instalar, activar su equipo y conectar únicamente las herramientas autorizadas.

1. ContrataciónEl cliente elige plan y módulos. El servidor crea su Customer ID y su licencia.
2. InstalaciónDescarga VentaNexIA Desktop e instala el programa en los equipos incluidos.
3. ActivaciónIntroduce Customer ID + código de activación. Cada ordenador consume una plaza.
4. ConexionesAutoriza correo, WhatsApp, CRM, carpetas, Shopify o portales privados según lo contratado.
5. PermisosSelecciona solo lectura o escritura por conexión. Las operaciones sensibles pueden requerir confirmación.
6. FuncionamientoYa puede pedir: “qué pedidos hay hoy”, “qué clientes son nuevos”, “responde este correo” o cualquier función habilitada.
Configuración recomendada: conecta primero cada fuente con permisos mínimos, valida los datos y amplía permisos únicamente cuando una función real lo necesite.
